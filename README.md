# wheel-reinvent

The Wheel Reinvent company page for partners at https://wheel-reinvent.com (GitHub Pages from `main`).

- `index.html` — English, `uk/index.html` — Ukrainian.
- `assets/site.css` — the look (plain: paper, ink, one dark-green accent; DzenQ in its own plum); light by default, dark with the moon button.
- Products are rows in «What we make / Що ми робимо»: add a new one by copying a `.row` (a link when the product has a site, a plain block while it's an idea).
