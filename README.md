# wheel-reinvent

The Wheel Reinvent company page for partners at https://wheel-reinvent.com (GitHub Pages from `main`).

- `index.html` — English, `uk/index.html` — Ukrainian.
- `assets/site.css` — the look (plain: paper, ink, one dark-green accent; DzenQ in its own plum); light by default, dark with the moon button.
- Products are rows in «What we make / Що ми робимо»: add a new one by copying a `.row` (a link when the product has a site, a plain block while it's an idea).
- `sunscript/` — Sunscript, the gesture keyboard (Ukrainian): what it is, a sandbox to try it in the browser, a training game, and the APK (`sunscript.apk`) until Google Play. Same look as this page (paper, ink, Inter, moon button); the three thumb-axis colours appear only in gesture drawings. Linked from the product list as a second `.feature` card.
- CSS and JS are linked with `?v=…` (`site.css?v=2`): bump it on every change so browsers and the Pages cache pick it up.
